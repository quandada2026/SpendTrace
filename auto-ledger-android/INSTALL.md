# 自动记账 App —— 安装与使用指南

> 适用对象：你本人（自用），Android 8.0 及以上手机。
> 本 App 通过**监听系统截图目录**实现「付完款 → 截图 → 自动记账、全程不碰 App」的零操作体验。

---

## 一、把 APK 装到手机

1. 把 `app-debug.apk` 传到手机（任选其一）：
   - 微信/QQ 文件助手发给自己 → 在手机上下载；
   - 数据线连电脑 → 复制到手机存储 `Download` 目录；
   - 任意网盘/邮件附件下载到手机。
2. 手机打开「文件管理」→ 找到 `app-debug.apk` → 点击安装。
3. 若提示「禁止安装未知来源应用」：点「设置」→ 允许本次来源（如「微信」「浏览器」或「文件管理」）→ 返回继续安装。
4. 安装完成，桌面出现「AutoLedger」图标。

> 这是 debug 签名包，仅供自用，无需 Google Play。手机需开启「允许未知来源」一次即可。

---

## 二、首次打开必须做的 3 件事

1. **开启监听**（主页底部按钮）：App 会请求「前台服务」权限（Android 14+ 必需，用于常驻后台监听截图），允许。
2. **授权读取图片/媒体**：用于读取截图内容做识别，必须允许（否则无法记账）。
3. **允许通知**（可选但建议）：识别完成会弹通知，方便确认。

授权后保持 App 在后台（不必打开），去付款、截图即可。

---

## 三、怎么用

- **零操作记账**：付款后按手机系统截图（电源键+音量下 / 三指下滑 / 你手机的双击背面等）→ 截图一落盘，App 自动 OCR → 识别金额/时间/商户/平台/分类 → 写入账本 → 弹通知。
- **查看账本**：打开 App 主页「账本」页，按时间倒序；顶部显示当月支出合计。
- **待核对**：识别不准（尤其金额没认出）的条目会标红在「待核对」页，点进去手动改金额/分类即可。
- **手动上传兜底**：没有双击截图功能的手机，或想补一张老截图 → 右上「上传」按钮选图，效果等同自动。
- **切换 OCR 引擎**：「设置」页默认用 **ML Kit 端侧识别**（免费、离线、隐私）。如想更准可填云端 OCR 的 endpoint/key 切到云端（需联网、可能有费用）。

## 三.5、v2.0 新增功能
- **周/月/年统计**：主页顶部卡片可切换「周 / 月 / 年」，显示当期**支出、收入、结余**及分类小计（周 = 周一到周日，国内习惯）。
- **手动记账**：右下角「+」按钮 → 选**支出/收入** → 填金额（必填）、选分类（必填）、商户/备注（可选）→ 保存即入账，无需截图。
- **支出/收入区分**：截图自动识别仍按支出入库；手动记账可记工资、转账等收入，统计分开汇总。

## 四、常见问题

- **第一次识别很慢 / 失败？** ML Kit 中文模型首次运行需联网下载（约几十 MB），之后离线。先连网用一次即可。
- **截图了没自动记账？** 检查：① 是否已「开启监听」；② 读取图片权限是否给了；③ 部分国产 ROM 会杀后台，把 App 加「白名单/电池优化忽略」。
- **金额识别错？** 支付截图布局各 App 不同，去「待核对」改一次，本引擎按规则解析，改完即正确入库。
- **想导出？** 当前版本本机 Room 存储，导出/月报图表为下一步功能（可让我加）。

## 五、构建说明（给技术备查）

- 由 `auto-ledger-core` 的解析/分类规则逐条移植为 Kotlin 纯函数，行为一致。
- 编译：`gradle assembleDebug`（本机用 `build_apk.ps1` 自动装 SDK 并产出 `app-debug.apk`）。
- 关键库：Jetpack Compose BOM 2024.06.00、Room 2.6.1、ML Kit `text-recognition-chinese:16.0.0`、Kotlin 1.9.24、AGP 8.5.2、compileSdk 34。
